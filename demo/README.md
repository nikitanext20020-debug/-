# NEURO.CORE — DEMO

Автономная **демо-версия** панели управления Telegram-ботом (авто-комментинг).

> ⚠️ Всё виртуально. Реальных аккаунтов, каналов и отправки сообщений нет —
> все данные фейковые и живут только в браузере. Ничего никуда не отправляется.
> Это витрина функционала, которую можно свободно «тыкать».

## Что показывает

- **Лента** — живая симуляция: бот находит посты в каналах, кидает заглушку `_`
  и на глазах редактирует её в текст нейросети, ставит реакции/лайки, изредка
  ловит флуд-лимит и снимает мягкий блок через `@SpamBot`.
- **Аккаунты** — готовый список аккаунтов со статусами (работает / спамблок /
  прогрев / остановлен). Кнопки старт/стоп/удалить работают локально.
- **Каналы** — база каналов с подписчиками и статусом комментов, поиск, удаление.
- **Поведение / Настройки** — все тоглы и поля активны (сохранение имитируется).
- **Логи** — живой поток событий с уровнями.

## Как это запустить

Это статический сайт — никакого бэкенда не нужно.

- **Локально:** просто открой `index.html` в браузере
  (или подними любой статический сервер: `python -m http.server`).
- **Деплой на Vercel:** залей эту папку как отдельный репозиторий и импортируй
  в Vercel — фреймворк не нужен, определится как static. Ссылку можно кидать другу.
- **GitHub Pages:** включи Pages для репозитория, корень — эта папка.
